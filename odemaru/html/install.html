【インストール】

　「おでかけマルチ」は、パソコン、P/ECE両方へのインストールが必要です。
 

●パソコンへの「P/ECE開発環境」のインストールがまだの方は

・P/ECE付属のCD-ROMをパソコンにセットしてください。

・「P/ECE開発環境」のインストールが始まります。
　P/ECE用開発キットなどとともに、「おでかけマルチ」がパソコンにインストールされます。

●すでに「P/ECE開発環境」をインストールされた方は

・P/ECEへのシステムのインストールはお済みですか？

・まだの方はまずP/ECEへのシステムのインストールを行ってください。
　詳しくはP/ECEのマニュアルをご参照ください。
　（「piece」フォルダの中の「index.htm」をブラウザでご覧ください。
　　「DOCUMENT」の中に、「システムのインストール」方法が載っています）
　

●P/ECEへのシステムのインストールまで終わっている方は

・「おでかけマルチ」を起動してください。
　「スタート」ボタン→「P/ECE」→「おでかけマルチ」から選択して起動します。

・オープニングムービーの後、（クリックでスキップできます）
　「P/ECEに「おでかけマルチ」をインストールします。
　　P/ECEを接続してください」
　というメッセージが出ますので、P/ECEをパソコンに接続してください。
　書き込み中はUSBケーブルを抜き差ししたり、P/ECE本体のリセットをかけたりしないでください。

・書き込みに成功すると、プロローグが始まります。
　プロローグの後は、どうぞP/ECEでゲームを進めてください。

・ときおりP/ECEのゲームを終了してから、パソコンと接続してみてください。
　絵日記やライバル図鑑が更新されていると思います。
 

【アンインストール】

・P/ECEの「おでかけマルチ」のアンインストールは、
　「P/ECEコミュニケータ」（「WinIsd」）を使ってWindowsから行ってください。
・パソコンの「おでかけマルチ」のアンインストールは、Windowsの
　「コントロールパネル」→「アプリケーションの追加と削除」
　から、「P/ECE開発環境」をアンインストールして行ってください。
