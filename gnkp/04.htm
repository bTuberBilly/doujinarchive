◆ Starting the Game　

　Double click "Gekka no Kishi+ English.exe" inside the "Gekka no Kishi+" folder to start the game, and wait until the title menu loads.
　If your PC's locale and system language are not set to Japanese, please launch the game using Locale Emulator.

・VS CPU
　　　Play a game against the CPU
・Network Match
　　　Create or join a LAN game
・Quit Game
　　　End the game and close its window

　Generally speaking, the game can be operated by using Left Click to confirm and Right Click to cancel.
　A fresh install of the game will start in Fullscreen Mode. You can change it to Windowed Mode with the F8 key.
　Also, you can capture the current state of the game window as a .bmp image by pressing F2. It saves to the root of the "Gekka no Kishi+" folder.

　※The characters in the bottom right are indicative of the version of the game you are playing.
　　Please note that game versions must match in order to participate in network games.
　　You can confirm that you have the latest version by visiting the itsumonotokoro webpage.
